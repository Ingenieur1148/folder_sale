Delete Done Picking

Force-delete validated stock transfers that are stuck in Done state — including their stock moves, move lines, and valuation layers.

⚠ Use with caution
Important: This module allows permanent deletion of done stock pickings. This action is irreversible and may affect your inventory valuation and accounting records. Only use it when you are certain the picking must be removed (e.g. test data, mistaken entries in a controlled environment).

Overview

In standard Odoo, validated (Done) stock transfers cannot be deleted — only cancelled under strict conditions. This module adds a Force Delete button directly on the transfer form that lets authorised users bypass this restriction and permanently remove the picking and all related data.

Features

🔴

Force Delete button

Red button visible only on Done transfers, right in the header bar.

📦

Full cleanup

Deletes stock moves, move lines, and unreserves quantities before removal.

💰

Valuation cleanup

Removes associated stock valuation layers to keep your costing clean.

↩️

Safe redirect

After deletion, automatically redirects to the Transfers list view.

How to use

1
Install the module from Settings → Apps. Search for Delete Done Picking.
2
Open a stock transfer that is in Done state (Inventory → Transfers).
3
Click the red Force Delete button in the header. Confirm the action.
4
The transfer and all related records are permanently removed. You are redirected to the transfers list.
